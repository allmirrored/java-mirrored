--- Відповіді на питання по Git ---
1. Команда git log вирішує проблему «хто змінив, коли і навіщо».
2. Команда git diff вирішує проблему «що саме змінилося».
3. Проблема поєднання роботи не має розв'язку аж до заняття 10.

--- Відкрита дискусія ---
1. Алгоритм — це абстрактна послідовність дій для вирішення задачі. Програма — це той самий алгоритм, але написаний конкретною мовою програмування, яку може виконати комп'ютер.
2. Мови програмування потрібні для людей, щоб писати, читати та підтримувати код у зрозумілому вигляді, а компілятор перекладає це в машинні команди для процесора.
3. Ні, комп'ютер не може зробити те, чого йому не казали. Навіть штучний інтелект працює за чітко заданими людиною алгоритмами.
4. Так, рецепт борщу є алгоритмом: він має вхідні дані, чітку послідовність інструкцій та очікуваний результат.
5. Алгоритм зав'язування шнурків: 1. Взяти по одному кінцю в кожну руку. 2. Перехрестити їх. 3. Протягнути один кінець під іншим. 4. Затягнути. 5. Зробити дві петлі. 6. Перехрестити петлі. 7. Протягнути одну петлю в отвір під ними. 8. Затягнути.
6. Ні, правильний підрахунок прикладів з дошки не доводить ідеальну роботу. Це лише один успішний тест, а програма може мати приховані помилки при інших вхідних даних.
