## B–F: код и проверки

Для 14 классов задач подготовлены 14 тестовых классов. Пакеты и пути
совпадают; перед каждым классом стоит только прямой URL LeetCode.
Убраны комментарии `base`/`advanced`. В исходниках задач нет TODO,
отладочной печати и однобуквенных переменных, кроме индексов циклов.
Каталоги используют ASCII и строчные буквы; вне `src/main`/`src/test`
не осталось компилируемых `.java`. В `src` нет других типов файлов.

Тесты содержат отдельные примеры LeetCode, допустимые минимумы и максимумы,
пустые строки там, где их разрешает условие, одиночные элементы, переносы,
переполнения, знаки и ветви циклов. Дополнительно проверяются все числа
1–3999 при преобразовании римских чисел и сетка знаковых делений.
Пустые массивы/строки не добавляются как обязательные границы там, где
условие LeetCode их запрещает. Числовые решения учитывают ограничения
задач: Divide Two Integers обходится без long, умножения, деления и остатка;
Reverse Integer не использует 64-битное хранение.

Все новые тесты детерминированы и содержат AssertJ-проверки. В защищённом
шаблонном `code/CalculatorPropertyTest.java` есть случайные property-тесты
без фиксированного seed и один метод без assert. По запрету менять `code`
они сохранены: при распространении F4/F6 на шаблон это остаётся исключением,
которое нужно обсудить с преподавателем. Флаг `-Djqwik.seed` не фиксирует
seed этой версии jqwik и не используется как доказательство F6.

## Компиляция и декомпиляция

В приложенных критериях E1–E4 требуются:

```shell
mvn clean compile
mvn test-compile
mvn test
mvn spotless:check
```

В репозитории не найден отдельный декомпилятор, скрипт его запуска или
инструкция преподавателя о декомпиляции. Maven компилирует `.java` в
`target/classes/*.class`. Декомпиляция — обратное восстановление текста из
`.class`, она не заменяет исходники и тесты, требуемые B1/B2.
JDK содержит `javap` для просмотра байткода, это не Java-декомпилятор.
Если преподаватель выдаст отдельную тулку, нужны её название и инструкция;
её проверка пока не выполнена. Сгенерированные `.class` в Git не добавлять.
