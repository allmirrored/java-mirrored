`lsof` заменён на `netstat.exe -ano`, идентификация процесса — `tasklist.exe`,
остановка — `taskkill.exe`, проверка TCP вместо nc — Python socket.
Конфликт воспроизведён через SO_EXCLUSIVEADDRUSE, поскольку повторный
запуск стандартного Python HTTP-сервера на этой Windows допускал reuse.
Это Windows-адаптация, а не доказательство выполнения буквально Linux-команд.
Если преподаватель требует именно Linux, эти замены нужно согласовать.

На снимке devops-14 также видна посторонняя ошибка вставки перед более ранним
echo для 8000: результат 127 не относится к TCP. Корректный результат
для 8000 отдельно показан в devops-13. На devops-16 после остановки остаётся
TIME_WAIT, что не является слушающим сервером.
